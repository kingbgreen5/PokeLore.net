# PokéLore Connected-Data Model

The strongest opportunity is to connect related pages rather than publishing isolated item descriptions.

Example:
Auspicious Armor
→ acquired in Zapapico
→ requires 10 Bronzor Fragments
→ evolves Charcadet into Armarouge
→ Scarlet-exclusive
→ links to Bronzor locations
→ links to Zapapico
→ links to Charcadet and Armarouge

Useful cross-links:
- Item → acquisition location
- Item → required Pokémon material
- Item → evolution result
- Pokémon → evolution item
- Pokémon → encounter locations
- Location → obtainable items
- Location → encountered Pokémon
- Move → TM or evolution requirement
- Guide → relevant item, Pokémon, and location pages
